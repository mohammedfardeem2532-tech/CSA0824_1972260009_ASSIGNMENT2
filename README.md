### Q1 – Decisions with Many Boundaries

- Compared independent `if` statements with `if-elif-else`.
- Tested subsidy eligibility under different conditions.

### Q2 – Loops that Count Attempts
- Implemented OTP verification using `while` and `for` loops.
- Handled blank entries.
- Limited verification attempts to three.

### Q3 – Vehicle Registration Number Validator
- Normalized vehicle registration numbers.
- Removed spaces and hyphens.
- Validated registration formats using string methods.
- Displayed valid and invalid registration numbers.

- Compared string concatenation using `+`.
- Implemented the `join()` method.
- Used f-strings to build long text.
- Compared execution time and output length.
