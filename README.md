## ⚙️ Key Concepts Covered

### 1. Conditional Statements
Used multiple conditions to determine subsidy eligibility based on units, ration card status, and senior citizen status.

### 2. Loops
Implemented `while` and `for` loops to verify OTP attempts and handle blank entries.

### 3. String Handling
Created a vehicle registration number validator using string methods such as `strip()`, `replace()`, `upper()`, `isalpha()`, and `isdigit()`.

### 4. String Concatenation
Compared different methods of building long strings:
- Using `+` operator
- Using `join()` method
- Using f-strings

### 5. Functions and Scope
Explored:
- Function parameters
- Default arguments
- Mutable default argument issues
- Global variables
- Nonlocal variables

### 6. Recursion
Compared three approaches:
- Normal recursion
- Memoization using `lru_cache`
- Iterative loop method

### 7. Program Optimization
Compared original and redesigned string-building methods and validated that both produce identical outputs.
